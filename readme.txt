            Setup Project
----------set virtual environment------------
1. pip install --upgrade pip
2. pip install virtualenv
3. virtualenv environment_name
----------------------------------------------

-------activate virtual environment-----------
1. cd environment_name/Scripts
2. write "activate" in cmd
----------------------------------------------
